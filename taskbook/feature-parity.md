# iOS/iPadOS Web UI 功能对照与验收

**目标：** 原生 SwiftUI 客户端对齐 WebSpeak 用户端可用能力，并遵循 iPhone/iPad 的系统交互、权限与媒体生命周期。行为对齐不意味着像素复刻。当前状态必须以实现和实际验证为准。

状态：`已接入，待端到端验收` = 已接入客户端行为并通过可用的构建检查，但尚无对应真机/网关证据；`部分实现` = 存在明确平台或能力缺口；`待实现/待评估` = 尚未接入或协议映射未确认；`已验收` 只能用于有对应测试/设备证据的能力。

## 分阶段验收

1. **工程与视觉基线：** Debug 构建；蓝色 App 图标；iPhone/iPad 自适应；Liquid Glass 与旧系统 Material 回退；动态字体和无障碍检查。
2. **连接纵切片：** `/api/public-config`、`/api/join-ticket`、`/ws/voice`；TS6 连接、当前用户/频道/成员、失败原因和断开状态。票据不落盘。
3. **实时语音：** WebRTC 双向音频与旧版 WebSocket PCM/Opus 兼容；后台、锁屏、耳机/蓝牙、来电打断、Wi-Fi/蜂窝切换和恢复设备测试。
4. **控制与消息：** 频道/成员操作、聊天、poke、私聊、耳语 PTT、音频偏好与实际服务端结果验证。
5. **屏幕共享与诊断：** P2P 观看和 iOS 27+ ScreenCaptureKit 发送；频道切换、用户撤销权限、退出/网络故障与性能统计。
6. **发布验收：** zh/en/de/ru/ja、Dynamic Type/VoiceOver/Reduce Motion、第三方许可清单、签名与分发；签名材料由 Timmy 保管。

## 明确不伪造的能力

- TeamSpeak 桌面客户端本地、从未经过 WebSpeak 网关的历史消息。
- iOS 系统不允许的后台启动、持续采集或用户强制停止后的自动恢复。
- 当前屏幕共享发送路径仅适用于 iOS 27+，且只发送画面；iOS 17–26 的系统级广播与系统音频尚未实现。
- 尚未端到端验证的 WebRTC、屏幕广播、蓝牙路由或所谓“零丢包/绝对保活”。
